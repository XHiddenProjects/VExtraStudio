# Night Shift: Tape 07

A 3D found-footage horror game. It is a normal Vextra block-graph project: open night-shift.vxgame in Vextra Studio and every behaviour is editable as blocks in the Logic tab (Intro, Lobby, Descent, Basement, Ascent, Rooftop, Ending).

build/night-shift.html is the playable web build made from those blocks.
